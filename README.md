# NextGen Coder LMS

An interactive Learning Management System (LMS) platform built to provide students with a modern learning experience. The platform allows users to access courses, track progress, manage content, and improve learning through a clean and user-friendly interface.

---

## 🚀 Features

* 🔐 User Authentication & Authorization
* 📚 Course Management
* 🎥 Video Lectures & Learning Resources
* 📚 Educator Dashboard
*  Payment gateway integration
*  AI Powered Search

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Other Tools

* Redux Toolkit
* JWT Authentication
* Cloudinary / Firebase

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/nextgen-coder-lms.git
```

### 2. Navigate to the Project Folder

```bash
cd nextgen-coder-lms
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Create Environment Variables

Create a `.env` file and add the following:

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
```

### 5. Run the Development Server

```bash
npm run dev
```

The application will run on:

```bash
http://localhost:3000
```
