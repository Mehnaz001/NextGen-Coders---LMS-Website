# 🎓 NextGen Coders 

Welcome to **NextGen Coders** – a modern **Learning Management System** where users can **learn** or **sell their own courses**!  
Built with the **MERN stack**, featuring **AI-powered search**, **secure payments**, and an **educator dashboard** to track analytics and earnings.  

---

## ✨ Features

### For Learners
- 🔍 AI-powered course search for faster discovery  
- 🎯 Browse & purchase courses with ease  
- 🟢 Google authentication for quick login/signup  

### For Educators
- 📚 Create & sell courses  
- ☁️ Upload video **lectures**  
- 📊 Track course analytics, student engagement & earnings  
- 🏆 Dashboard for performance insights  

### 💳 Payments
- 🔒 Secure payment gateway integration  
- 💰 Easy tracking of transactions & earnings  

---

## 🛠️ Tech Stack

| Feature | Technology |
|---------|------------|
| Frontend | React.js |
| Backend | Node.js & Express.js |
| Database | MongoDB Atlas |
| Media Upload | Cloudinary |
| Search | Gemini AI |
| Authentication | Firebase (Google Auth) |
| Payments | RazorPay Payment Gateway |
| Hosting | (Render,Vercel) |

## ⚡ Getting Started

### Prerequisites
- Node.js & npm installed  
- MongoDB database  
- Cloudinary account  
- Firebase project  
- Payment gateway account  

### Installation
```bash
# Clone the repo
git clone https://github.com/yourusername/nextgen-coders-lms.git
cd nextgen-coders-lms

# Install dependencies
npm install

# Create a .env file and add your credentials
# Example:
# MONGO_URI=your_mongodb_connection_string
# CLOUDINARY_CLOUD_NAME=your_cloud_name
# CLOUDINARY_API_KEY=your_api_key
# CLOUDINARY_API_SECRET=your_api_secret
# FIREBASE_API_KEY=your_firebase_api_key
# PAYMENT_GATEWAY_KEY=your_payment_key

# Start the development server
npm run dev
```
